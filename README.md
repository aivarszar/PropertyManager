# Property Manager - PHP + MySQL Version

Property Manager ir īpašumu pārvaldības sistēma, kas ļauj namu īpašniekiem un īrniekiem efektīvi pārvaldīt īres attiecības, maksājumus un komunicēt par saimnieciskajām problēmām.

## 🚀 Galvenās Funkcijas

### Īpašniekiem:
- ✅ Reģistrēt un pārvaldīt īpašumus
- ✅ Pievienot īrniekus ar uzaicinājuma kodiem
- ✅ Pārvaldīt maksājumus
- ✅ Apstiprināt maksājuma apstiprinājumus
- ✅ Skatīt problēmu ziņojumus

### Īrniekiem:
- ✅ Reģistrēties ar kodu
- ✅ Skatīt maksājumus
- ✅ Augšupielādēt apstiprinājumus
- ✅ Ziņot par problēmām

## 💻 Tehnoloģijas

- PHP 7.4+
- MySQL 5.7+
- PDO
- Session-based Auth
- HTML/CSS/JS
